Triage, not just collection

Thousands of archived URLs are noise until you can sort them. The results page does that for you.

  • Risk ranking.env, .git, SQL dumps and .bak files surface first, each tagged by file type.
  • Status filterHide the dead captures with Only 200, or isolate the 404s.
  • Verify liveOptional HEAD checks show which URLs respond right now, for in-scope targets only.
  • ExportCopy, TXT, CSV, JSON, or just the unique hosts as a passive subdomain list.

Install in a minute

Not on the Chrome Web Store yet, so you load it from source. Works in Chrome, Edge and Brave.

  1. Clone the repository.
    git clone https://github.com/pratik-khairnar-sec/wayback-lens.git
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and choose the project folder, then pin the icon.

Small footprint, no tracking

activeTab

Reads the current tab URL to pre-fill the target, only when you open the popup.

storage

Remembers your options and five recent targets, locally.

web.archive.org

The only site it contacts by default, to query the public CDX API.

Optional: live sites

Requested only when you click Verify live. Revoke it any time.

Use it on authorized targets. Archive data is public, but probing live hosts is not automatically permitted. Stay within bug bounty scope or written permission.
