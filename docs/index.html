Targeted Scan Modes

Six specialized recon scopes designed to extract exactly what matters for your engagement.

Main Domain (Host Scope)

Every archived URL on the exact hostname. url=host/*

All Subdomains

Passive subdomain enumeration covering the root host and all subdomains. matchType=domain

Sensitive Files

Backups (.bak, .sql), private keys, .env, configs, logs, and dumps.

JavaScript Bundles

Archived .js and .mjs files to uncover hidden API endpoints and leaked keys.

With Parameters

Query-string endpoints ready to feed into fuzzers for SSRF, SQLi, and IDOR testing.

Extension Popup: pre-fills active tab, previewing live CDX query.

Engineered for High-Velocity Recon

Built from scratch to overcome the slow, clunky, and memory-heavy limitations of legacy archive extractors.

Non-Blocking Stream Processing

Uses chunked ReadableStream parsing to ingest and display 100,000+ CDX records without lagging your browser or eating gigabytes of RAM.

Heuristic Risk Scoring

Pre-filters noise and surfaces high-value targets first: .env files, AWS tokens, SQL database dumps, .git directories, and backup archives.

Live HEAD Verification

Multi-worker prober checks which historical URLs actually respond with HTTP 200 today, helping you find active vulnerable endpoints instantly.

Instant Regex & Faceted Filters

Filter on-the-fly by HTTP status code, target subdomain, query parameters, or arbitrary Regular Expressions with zero round-trip delay.

Universal Export Suite

Export your tailored triage view as clean TXT, CSV, JSON, or extract a deduplicated passive subdomain host list ready to pipe into subfinder or httpx.

100% Offline UI & Zero Telemetry

Zero third-party analytics, zero cloud dependencies, strict Manifest V3 CSP, and inline SVG assets. Captured URLs are sanitized and never executed.

Quick Start Guide

Install in under 60 seconds on any Chromium-based browser (Chrome, Brave, Edge, Arc, Opera).

1

Clone or Download

Grab the official release ZIP or clone the repository:

git clone https://github.com/pratik-khairnar-sec/wayback-lens.git

2

Enable Developer Mode

Open chrome://extensions in your browser and switch on the Developer mode toggle in the top-right corner.

3

Load Unpacked

Click Load unpacked and select the project folder. Pin the extension icon to your toolbar for immediate access.

Responsible Reconnaissance & Scope Notice: While Wayback Machine archives represent public historical telemetry, probing active production endpoints with the Verify Live feature must only be conducted against targets within authorized bug bounty scope or under explicit penetration testing permission.
